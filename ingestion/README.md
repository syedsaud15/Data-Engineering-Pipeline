# Data Ingestion Layer

## Overview

The ingestion layer is responsible for collecting data from different source systems and loading it into the data platform.

## Data Sources

- CSV Files
- APIs
- Databases
- Cloud Storage
- Streaming Sources

## Technologies Used

- Python
- Apache Kafka
- Azure Data Factory
- AWS S3

## Ingestion Flow

Source Systems  
↓  
Data Extraction  
↓  
Data Validation  
↓  
Raw Data Storage

## Responsibilities

- Extract data from multiple sources
- Perform initial validation
- Maintain data quality
- Load raw data into storage layer
